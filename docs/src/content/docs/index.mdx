## Highlights

<CardGrid>
  <Card title="Live chats over your data" icon="comment">
    Each route is a real chat over Microsoft 365 data, read with the signed-in user's permissions. There are no sample answers.
  </Card>
  <Card title="Every call in view" icon="list-format">
    **Flow** shows each step between you, the model and Work IQ, with latency, tokens, a Copilot Credits estimate and the raw payloads.
  </Card>
  <Card title="The code that runs it" icon="seti:javascript">
    **Code** shows the app's actual source beside the chat: a Deep Agents harness, A2A JSON-RPC and two REST calls.
  </Card>
  <Card title="Three routes, side by side" icon="random">
    MCP, local or remote, with your own model; A2A to delegate a task; REST for a grounded chat inside your app.
  </Card>
  <Card title="Sign-in, explained" icon="padlock">
    What each route needs to sign in, what an admin grants once, and the recommended setup for your own tool.
  </Card>
  <Card title="Windows, macOS and Linux" icon="laptop">
    Download the app for x64 or Arm, or run it from source with Node.js.
  </Card>
</CardGrid>

Every route needs a Microsoft 365 tenant with Work IQ enabled and a usage-based billing plan; both MCP routes also need a model with tool calling. See [What you need](getting-started/what-you-need/).
